# CheckList 01. 로그인 씬 이미지 선택

- 로그인 씬에 파일 첨부 버튼이 배치되어 있습니다.
- 버튼 `OnClick`이 `sh_LoginSceneController` 또는 연결 메서드에 등록되어 있습니다.
- 안드로이드 기기에서 버튼 클릭 시 이미지 선택 창이 열립니다.
- `jpg`, `jpeg`, `png` 파일을 선택할 수 있습니다.
- 이미지 선택 성공 시 성공 로그 또는 안내 문구가 표시됩니다.
- 이미지 선택 취소 시 오류 없이 로그인 씬에 머뭅니다.
- 선택 실패 시 원인 확인 가능한 오류 로그가 출력됩니다.

## 통과 조건
- 실제 기기 또는 플러그인 지원 환경에서 이미지 선택 창 호출이 재현됩니다.
