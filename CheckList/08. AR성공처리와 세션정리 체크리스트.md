# CheckList 08. AR 성공 처리와 세션 정리

- AR 씬에 `AR Session`이 있습니다.
- 현재 프로젝트 기준 `XR Origin` 계열 오브젝트가 있습니다.
- `AR Tracked Image Manager`가 설정되어 있습니다.
- 마커 인식 성공 시 `과거의 추억을 되찾았습니다` 문구가 표시됩니다.
- 로그인 복귀 버튼이 나타나거나 활성화됩니다.
- 버튼 클릭 시 로그인 씬으로 이동합니다.
- 로그인 씬 복귀 후 원본 이미지가 삭제됩니다.
- `MarkerImage` 하위 1차 조각이 삭제됩니다.
- `RotatingImage` 하위 2차 조각이 삭제됩니다.

## 통과 조건
- AR 성공 처리 후 로그인 복귀와 생성 파일 정리가 한 번에 확인됩니다.
