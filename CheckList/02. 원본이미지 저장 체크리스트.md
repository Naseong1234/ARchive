# CheckList 02. 원본 이미지 저장

- 이미지 선택 직후 저장 함수가 호출됩니다.
- `ARchive_AI/Assets/Data/Image` 경로가 없으면 자동 생성되거나 사전 준비되어 있습니다.
- 원본 이미지 파일이 지정한 이름 규칙으로 1개 저장됩니다.
- 저장 후 경로 문자열을 다른 시스템이 전달받을 수 있습니다.
- 저장 실패 시 예외 없이 실패 로그가 남습니다.
- 이전 테스트 파일과 현재 테스트 파일을 구분할 수 있습니다.

## 통과 조건
- 저장 후 폴더에서 실제 이미지 파일을 직접 확인할 수 있습니다.
