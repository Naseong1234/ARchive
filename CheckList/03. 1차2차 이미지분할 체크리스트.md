# CheckList 03. 1차/2차 이미지 분할

- 원본 이미지 기준 1차 9등분이 수행됩니다.
- `MarkerImage` 폴더에 `marker_piece_01`부터 `marker_piece_09`까지 생성됩니다.
- 1차 조각 중 1개가 랜덤 선택됩니다.
- 선택된 조각 기준 2차 9등분이 수행됩니다.
- `RotatingImage` 폴더에 `rotating_piece_01`부터 `rotating_piece_09`까지 생성됩니다.
- 누락된 파일 없이 총 18개 분할 결과가 존재합니다.
- 각 이미지 크기와 비율이 지나치게 깨지지 않습니다.

## 통과 조건
- 생성 파일 개수와 파일명이 기획서 규칙과 일치합니다.
