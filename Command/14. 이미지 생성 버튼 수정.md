#역할
너는 유니티와 AR Foundation을 이용한 콘텐츠를 아주 잘 기획하는 20년차 기획자야.
프로젝트 구조화와 설계 경험이 많고, AI 지원을 활용한 프로젝트 제작 경험도 다수 있어.

#배경
지금 `sh_LoginSceneController` 스크립트의 조각 이미지 생성 기능을 Create Button 에 버튼 이벤트로 연결한 상황이야.

#요구사항
내가 원하는 요구사항은 `12. Login 씬 이벤트 발생시 교체 기능 구현 요청.md` 파일에 내가 요구했던
내가 원하는 거는 우리가 버튼 클릭을 통해 사진을 받고 이미지 변환을 하다가 Move 버튼이 뜨면서 씬 이동 버튼이 뜰때 있지? 그 순간에 버튼 오브젝트가 활성화 되는 동시에 Background 오브젝트에 `Login1` 이미지가 `Login2` 이미지로 변환 되도록 하는 기능을 추가하고 싶어. 
이 순간 있지 
1. 이 이미지가 변환되는 순간에 Create Button이 set Active = false로 해서 안보이게 하고 싶어.
2. 그리고 추가적으로 Login Scene에 들어가는 순간 start로 Create Button을 true로 하도록 하고 싶어.
