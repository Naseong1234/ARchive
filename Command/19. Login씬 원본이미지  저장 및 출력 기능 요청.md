# 역할
너는 유니티와 AR Foundation을 이용한 콘텐츠를 아주 잘 기획하는 20년차 기획자야.
프로젝트 구조화와 설계 경험이 많고, AI 지원을 활용한 프로젝트 제작 경험도 다수 있어.

# 배경
이미지를 첨부하고, AR씬의 마커이미지 인식이후, Login씬으로 돌아오게 되잖아?

원래는 그렇게 Login 씬으로 돌아오면 다시 처음부터 하면 되는데. 
여기에서 한가지 과정을 추가하고 싶어.

1. 첫번째 기능
바로 AR씬의 마커이미지 인식이후, Login씬으로 돌아오게 될경우 이번과정을 통해 사용했던 모든 사진 데이터를 제거함으로써 데이터 관리를 했잖아?

근데 내가 수정하고 싶은 사항은 모든 사진을 삭제하지 말고 원본이미지만 삭제하지 말고 따로 핸드폰 정보에 저장하고 싶어

// 기기에 데이터 저장 준비 (Set)
PlayerPrefs.SetInt("Score", 100);             // 정수형 데이터
PlayerPrefs.SetString("PlayerName", "Hero");  // 문자열 데이터
PlayerPrefs.SetFloat("Volume", 0.5f);         // 실수형 데이터

// 물리적 기기에 최종 기록
PlayerPrefs.Save();

로 데이터를 저장할수 있으면 해주고 이 방법이 안되면 다른 방법으로 저장해서
스마트폰을 껐다가 다시 접속해도 원본 이미지에 대한 데이터가 저장되어 있도록 하고 싶어.



2. 두번째 기능
이런식으로 저장한 원본이미지는 최대 6개 까지 저장할수 있고, 이 데이터는 큐 형식으로
관리해서 가장 오래된 원본 이미지는 제거 되도록 구현 해줘.

3. 세번째 기능
이렇게 저장된 원본이미지는 내가 실제로 배치할 위치만 담은 오브젝트, 그리고 어느정도 사이즈로 출력할지를 담은 prefab을 넣어줄 태니, 그 위치와, 그 사이즈로 원본이미지를 출력하도록 하는 기능
-> 이 기능은 내가 기존에 만들었던 코드를 참고하면 금방 구현 할수 있을거야.


# 요구사항
이 # 배경의 1. 첫번째 기능, 2. 두번째 기능, 3. 세번째 기능 을 구현하는 방법을 `Tasks`폴더의 task를 추가해줘.

# 중요사항
이 추가 기능은 `sh_LoginSceneController` 에 추가하는 식으로 구현해줘.
