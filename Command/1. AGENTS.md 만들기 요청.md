#주요기능
-사용자로부터 사진을 제공 받은이후, 사진을 동일한 비율로 9개로 잘라서 이미지를 각각 생성
-각각의 생성된 이미지는 원본기준 9등분을 해서 왼쪽 위부터 1번~9번의 번호를 같게 되고
-그 1~9번 이미지 중 랜덤으로 1개의 이미지를 선택해서 또다시 사진을 동일한 비율로 9개로 잘라서 이미지를 각각 생성하고 1번~9번의 번호를 같도록 해줘.
-이렇게 2번의 과정을 거쳐 생성된 각각의 생성된 이미지는 랜덤으로 0,90,180,270 중 하나의 rotation 값을 받게되고, 이 사진을 내가 설정한 유니티의 버튼 UI의 상에 뛰울수 있도록 조정
-UI에는 사용자가 클릭할수 있는 버튼을 "이동"과 "회전" 이 2가지의 상호작용 버튼을 만들 예정이야.
-기본적으로 맨처음에는 UI 클릭해도 아무런 상호작용이 없고, 
조각난 이미지 터치 + "이동" UI 버튼 = 조각난 이미지 오브젝트 이동가능
조각난 이미지 터치 + "회전" UI 버튼 = 조각난 이미지 오브젝트의  rotation 값이 + 90씩 회전
하도록 구현할 생각이야.

-메인씬에서는 1. 조각난 이미지를 집어 넣을수 잇는 액자 UI와 2.조각난 이미지가 모여있는 빈 액자 이미지가 있어. 자 여기서 내가 원하는거는 조각난 이미지클릭 + "이동" UI 버튼 상황을 통해 
2번인 빈 액자속 조각난 이미지를 드래그 해서 -> 1번인 이미지를 집어 넣을수 있는 액자로 이동하여 
9개의 빈 구역중 한곳에 이미지를 드래그한후 손을 땐 순간 조각난 이미지가 빈구역중 가장 겹치는 곳에 조각난 이미지가 집어 넣을수 있는 액자의 한 구역의 source image로 들어가게 하는 기능을 구현하고 싶어.

-이런 식으로 랜덤하게 회전이 되어 있는 사진들이 원래의 기존 모양인 0도 즉 올바른 회전율로 되어있고,
이미지를 넣을수 있는 액자 UI 액자의 1번위치 = 조각난 이미지의 1번 위치
이런식으로 동일한 위치로 9개의 조각난 이미지 모두, 정해진 위치에  source image로 들어가게 되면 
조각을 모았다는 이미지가 뜨면서 추가로 내가 설정한 AR씬으로 넘어가는 버튼이 뜨도록 만들거야.

-버튼을 클릭함으로써 AR씬으로 넘어간 다음에는 방금 내가 



1.앱을 실행 하면 로그인 창이 먼저 뜰거야. 
2.사용자가 입장하기 버튼을 통해 "SettingScene"이라는 Scene을 들어가게 될거야.
3."SettingScene"이라는 Scene에서는 한가지 기능만 있으면되. 우리가 사진을 첨부하는 기능이 있잖아?
그 사진을 첨부하는 기능을 통해 우선 사용자가 만들고 싶은 사진을 제공 받는게 첫번째 스텝이야.
