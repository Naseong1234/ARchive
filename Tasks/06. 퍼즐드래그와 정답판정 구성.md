# Task 06. 퍼즐 드래그와 정답 판정 구성

## 목표
- 사용자가 퍼즐 조각을 드래그해서 슬롯에 배치할 수 있게 만듭니다.
- 모든 조각이 올바른 슬롯에 들어갔을 때 퍼즐 완료를 판정합니다.

## 구현 범위
- `sh_PuzzleDragHandler` 생성
- 드래그 시작, 이동, 종료 처리
- 슬롯 근접 시 스냅 또는 고정 처리
- 조각별 정답 슬롯 비교
- 전체 퍼즐 완료 상태 판정

## 예상 결과
- 사용자가 손가락 또는 마우스로 조각을 움직일 수 있습니다.
- 올바른 슬롯에 배치된 조각은 정답 상태가 됩니다.
- 9개 모두 정답이면 완료 이벤트가 호출됩니다.

## 선행 준비
- 퍼즐 조각 UI 생성 완료
- 슬롯 번호 체계 준비 완료

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/sh_PuzzleDragHandler.cs`
- `ARchive_AI/Assets/Data/Scripts/sh_PuzzleBoardController.cs`

## 유니티에서 사용자가 할 일
- 퍼즐 조각 프리팹에 `CanvasGroup` 추가
- 필요 시 `Raycast Target` 설정 확인
- 드래그 가능한 상위 `Canvas`가 `Screen Space` 기준으로 정상 동작하는지 확인

## 완료 기준
- 조각 드래그가 끊기지 않고 자연스럽게 동작합니다.
- 오답 슬롯에 놓으면 정답 처리되지 않습니다.
- 9개 정답 완료 시 완료 이벤트가 정확히 1회 발생합니다.
