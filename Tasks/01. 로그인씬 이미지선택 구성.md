# Task 01. 로그인 씬 이미지 선택 구성

## 목표
- 로그인 씬에서 사용자가 사진을 선택할 수 있는 시작 흐름을 만듭니다.
- 안드로이드 환경 기준으로 이미지 선택 버튼과 선택 결과 수신 구조를 연결합니다.

## 구현 범위
- `sh_LoginSceneController` 생성
- `sh_ImagePickerService` 생성
- 파일 첨부 버튼 클릭 이벤트 연결
- `jpg`, `jpeg`, `png` 필터 기준 정리
- 선택 성공 / 취소 / 실패 상태 분기 처리

## 예상 결과
- 사용자가 로그인 씬에서 `파일 첨부` 버튼을 누를 수 있습니다.
- 기기 이미지 선택 창이 열립니다.
- 이미지 선택 후 게임이 다음 처리 단계로 넘어갈 수 있는 경로 문자열 또는 바이트 데이터를 확보합니다.

## 선행 준비
- 로그인 씬에 `Canvas`와 큰 버튼 UI 배치
- 파일 첨부 버튼용 `Button` 컴포넌트 준비
- 선택 상태를 보여줄 안내 텍스트 준비

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/sh_LoginSceneController.cs`
- `ARchive_AI/Assets/Data/Scripts/sh_ImagePickerService.cs`

## 유니티에서 사용자가 할 일
- 로그인 씬의 빈 오브젝트에 `sh_LoginSceneController` 부착
- 파일 첨부 버튼의 참조를 Inspector에 연결
- 상태 안내용 `Text` 또는 `TMP_Text` 참조 연결
- 안드로이드 이미지 선택 플러그인을 쓸 경우 패키지 또는 플러그인 설치 상태 확인

## 완료 기준
- 버튼 클릭 시 이미지 선택 창 호출이 시작됩니다.
- 이미지 선택 성공 시 콘솔 또는 UI에 성공 상태가 표시됩니다.
- 이미지 선택 취소 시 앱이 멈추지 않고 로그인 씬에 그대로 유지됩니다.
