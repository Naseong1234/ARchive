# Task 09. Login씬 원본이미지 보관 및 출력 구성

## 목표
- AR 씬 복귀 후에도 원본 이미지를 삭제하지 않고 기기에 계속 보관합니다.
- 보관한 원본 이미지를 로그인 씬에서 최대 6개까지 큐 방식으로 관리합니다.
- 사용자가 배치한 위치 오브젝트와 프리팹 크기를 그대로 사용해 보관 이미지를 출력합니다.

## 구현 범위
- `sh_LoginSceneController`에 원본 이미지 보관 큐 추가
- `PlayerPrefs`에 보관 목록 메타데이터 저장
- 실제 이미지 파일은 `persistentDataPath` 하위 보관 폴더에 저장
- 최대 6개 초과 시 가장 오래된 원본 이미지 자동 삭제
- 로그인 씬 진입 시 저장된 원본 이미지 프리뷰 자동 생성
- 사용자가 배치한 출력 위치 오브젝트 배열 기준으로 프리팹 배치

## 예상 결과
- 앱을 종료했다가 다시 실행해도 보관 원본 이미지 목록이 유지됩니다.
- 새 이미지를 저장하면 가장 최근 이미지가 로그인 씬에 표시됩니다.
- 7번째 이미지부터는 가장 오래된 이미지가 먼저 제거됩니다.

## 선행 준비
- 로그인 씬에 `sh_LoginSceneController`가 붙은 오브젝트 준비
- 원본 이미지를 출력할 프리팹 1개 준비
- 출력 위치만 잡아둘 `RectTransform` 오브젝트를 최대 6개까지 배치

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/Scene/sh_LoginSceneController.cs`

## 유니티에서 사용자가 할 일
- `sh_LoginSceneController`가 붙은 오브젝트에 아래 참조를 연결합니다.
- `Archived Image Preview Prefab`에 원본 이미지 표시용 프리팹을 연결합니다.
- `Archived Image Preview Root`에 프리팹이 생성될 부모 UI 오브젝트를 연결합니다.
- `Archived Image Preview Points` 배열에 사용자가 배치한 위치 오브젝트를 순서대로 넣습니다.
- 필요하면 `Max Archived Image Count`를 6으로 유지하고, `Archived Image Folder Name`은 기본값 그대로 사용합니다.
- 프리팹 내부 `Image`, `RectTransform`, 필요 시 `AspectRatioFitter` 연결 상태를 확인합니다.

## 완료 기준
- 로그인 씬에서 이미지 선택 후 퍼즐 데이터 생성이 정상 완료됩니다.
- AR 씬을 거쳐 로그인 씬으로 돌아와도 보관 원본 이미지가 남아 있습니다.
- 앱을 완전히 종료 후 재실행해도 보관 원본 이미지 프리뷰가 다시 표시됩니다.
- 6개를 초과해서 저장하면 가장 오래된 원본 이미지 파일과 목록 정보가 제거됩니다.

## 확인 메모
- `PlayerPrefs`는 파일 자체가 아니라 보관 목록 정보만 저장합니다.
- 실제 원본 이미지는 `Application.persistentDataPath/Data/Image/LoginOriginalArchive` 폴더에 저장됩니다.
