# Task 08. AR 성공 처리와 세션 정리 구성

## 목표
- AR 씬에서 이미지 트래킹 성공 시 완료 메시지와 복귀 버튼을 보여줍니다.
- 로그인 씬으로 돌아갈 때 이번 세션에서 생성한 파일을 정리 삭제합니다.

## 구현 범위
- `sh_ARSceneController` 생성
- `sh_ARTrackingResultHandler` 생성
- `sh_SessionCleanupService` 생성
- 이미지 트래킹 성공 이벤트 처리
- `과거의 추억을 되찾았습니다` 메시지 표시
- 로그인 씬 복귀 버튼 표시
- 복귀 시 원본, 1차, 2차 생성 파일 삭제

## 예상 결과
- 마커 인식 성공 후 AR 완료 UI가 나타납니다.
- 로그인 씬 복귀 시 생성 이미지가 남지 않습니다.

## 선행 준비
- AR 씬에 `AR Session`
- 현재 프로젝트 버전에 맞는 `XR Origin`
- `AR Tracked Image Manager`
- Reference Image Library 연결 구조 준비

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/sh_ARSceneController.cs`
- `ARchive_AI/Assets/Data/Scripts/sh_ARTrackingResultHandler.cs`
- `ARchive_AI/Assets/Data/Scripts/sh_SessionCleanupService.cs`

## 유니티에서 사용자가 할 일
- AR 관련 오브젝트를 씬에 직접 배치
- `AR Tracked Image Manager`가 추적 이벤트를 받을 수 있게 설정
- 성공 메시지 UI와 로그인 복귀 버튼 연결
- 로그인 씬 이름과 복귀 경로 확인

## 완료 기준
- 마커 인식 성공 시 성공 UI가 1회 표시됩니다.
- 로그인 복귀 버튼이 정상 동작합니다.
- 복귀 후 `Assets/Data/Image` 하위 생성 파일이 정리됩니다.

## 최종 완료 기준
- 로그인 -> 퍼즐 -> AR -> 로그인 복귀 전체 흐름이 한 세션으로 연결됩니다.
