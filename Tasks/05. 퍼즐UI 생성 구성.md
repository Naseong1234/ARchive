# Task 05. 퍼즐 UI 생성 구성

## 목표
- 저장된 조각 이미지를 유니티 UI `Image`에서 쓸 수 있는 스프라이트로 변환합니다.
- 퍼즐 씬에서 9개 조각과 9개 슬롯을 기본 배치합니다.

## 구현 범위
- 텍스처 로드
- 스프라이트 변환
- `sh_PuzzleBoardController` 기본 생성
- 퍼즐 조각 UI 프리팹 생성 및 배치
- 슬롯 번호 체계 연결

## 예상 결과
- 퍼즐 씬에서 회전된 조각 9개가 보입니다.
- 9개의 슬롯이 정답 번호 기준으로 식별됩니다.

## 선행 준비
- 퍼즐 씬 제작
- 퍼즐 조각 프리팹에 `Image` 컴포넌트 준비
- 슬롯 오브젝트 9개 준비

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/sh_PuzzleBoardController.cs`
- 필요 시 `sh_PuzzlePieceData.cs` 연동

## 유니티에서 사용자가 할 일
- 퍼즐 씬의 빈 오브젝트에 `sh_PuzzleBoardController` 부착
- 퍼즐 조각 프리팹 연결
- 9개 슬롯 Transform 또는 슬롯 스크립트 참조 연결
- `Canvas`, `GraphicRaycaster`, `EventSystem` 존재 여부 확인

## 완료 기준
- 퍼즐 씬 진입 시 9개 조각이 생성됩니다.
- 각 조각 이미지가 정상 표시됩니다.
- 슬롯 식별 번호와 퍼즐 조각 데이터가 서로 연결됩니다.
