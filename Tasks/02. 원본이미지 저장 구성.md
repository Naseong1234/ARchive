# Task 02. 원본 이미지 저장 구성

## 목표
- 선택한 이미지를 런타임 작업용 경로에 저장합니다.
- 이후 퍼즐 분할과 AR 흐름이 공통으로 참조할 원본 파일을 고정합니다.

## 구현 범위
- `sh_ImageStorageService` 생성
- 원본 이미지 저장 경로 생성
- 이전 세션 파일과 구분 가능한 파일명 규칙 적용
- 저장 성공 / 실패 결과 반환 구조 작성

## 예상 결과
- 선택한 이미지가 `Assets/Data/Image` 기준 경로에 저장됩니다.
- 저장된 파일 경로를 다음 시스템에서 재사용할 수 있습니다.

## 선행 준비
- `ARchive_AI/Assets/Data/Image` 폴더 존재 여부 확인
- 저장 파일명 예시 `user_source.jpg` 또는 세션 기반 이름 규칙 결정

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/sh_ImageStorageService.cs`
- 필요 시 `sh_LoginSceneController` 연동 수정

## 유니티에서 사용자가 할 일
- 저장 서비스가 붙을 매니저 오브젝트 준비 또는 로그인 씬 컨트롤러 내부에서 참조 연결
- 저장 완료 후 상태를 보여줄 안내 텍스트 연결
- 에디터 테스트 시 실제 저장 경로에 파일이 생성되는지 폴더에서 확인

## 완료 기준
- 이미지 선택 직후 저장 함수가 호출됩니다.
- 지정 폴더에 원본 이미지 파일이 1개 생성됩니다.
- 저장 실패 시 원인을 확인할 수 있는 로그가 출력됩니다.

## 다음 Task 연결
- 저장한 원본 이미지를 1차, 2차 9등분으로 분할하는 Task로 진행합니다.
