# Task 07. 퍼즐 완료와 AR 씬 전환 구성

## 목표
- 퍼즐 완료 후 사용자에게 명확한 완료 메시지를 보여줍니다.
- AR 씬으로 이동하는 버튼을 활성화합니다.

## 구현 범위
- `sh_PuzzleResultController` 생성
- `기억의 조각을 수집하였습니다` 메시지 표시
- `AR 씬으로 이동` 버튼 활성화 또는 생성
- 버튼 클릭 시 AR 씬 전환

## 예상 결과
- 퍼즐이 완료되면 즉시 완료 UI가 나타납니다.
- 사용자가 큰 버튼으로 다음 단계로 이동할 수 있습니다.

## 선행 준비
- 퍼즐 완료 이벤트 연결
- 빌드 세팅에 퍼즐 씬과 AR 씬 등록

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/sh_PuzzleResultController.cs`

## 유니티에서 사용자가 할 일
- 완료 메시지용 UI 오브젝트 준비
- AR 이동 버튼용 `Button` 준비
- 초기 상태를 비활성화해 두고 완료 후 활성화되게 설정
- `SceneManager`로 이동할 씬 이름이 정확한지 확인

## 완료 기준
- 퍼즐 완료 시 메시지가 바로 표시됩니다.
- AR 이동 버튼이 나타나고 정상 클릭됩니다.
- 클릭 시 AR 씬으로 전환됩니다.
