# Task 03. 1차/2차 이미지 분할 구성

## 목표
- 원본 이미지를 3x3으로 분할하고, 그중 랜덤 1개를 다시 3x3으로 분할합니다.
- 퍼즐과 마커 준비에 필요한 파일 세트를 생성합니다.

## 구현 범위
- `sh_ImageSliceService` 생성
- 원본 이미지 1차 9등분
- `MarkerImage` 폴더 저장
- 1차 결과 중 랜덤 1개 선택
- 선택 조각 2차 9등분
- `RotatingImage` 폴더 저장
- 파일명 규칙 고정

## 예상 결과
- `marker_piece_01~09.png` 생성
- `rotating_piece_01~09.png` 생성
- 랜덤 선택된 1차 조각 정보가 데이터로 보관됩니다.

## 선행 준비
- `ARchive_AI/Assets/Data/Image/MarkerImage`
- `ARchive_AI/Assets/Data/Image/MarkerImage/RotatingImage`
- 텍스처 읽기 및 PNG 저장 방식 결정

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/sh_ImageSliceService.cs`
- `ARchive_AI/Assets/Data/Scripts/sh_ImageStorageService.cs`

## 유니티에서 사용자가 할 일
- 테스트용 버튼 또는 자동 실행 흐름으로 분할 함수를 호출할 수 있게 연결
- 실행 후 실제 폴더에 18개 결과물이 생성되는지 확인
- 원본 비율이 심하게 찌그러지지 않는지 확인

## 완료 기준
- 원본 기준 1차 조각 9개가 순서대로 생성됩니다.
- 랜덤으로 고른 1개 조각에서 2차 조각 9개가 생성됩니다.
- 누락 파일 없이 총 18개 이미지가 저장됩니다.
