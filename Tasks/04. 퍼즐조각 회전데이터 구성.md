# Task 04. 퍼즐 조각 회전 데이터 구성

## 목표
- 2차 분할된 9개 조각에 난이도용 랜덤 회전값을 부여합니다.
- 퍼즐 조각별 정답 슬롯 번호와 현재 회전 상태를 함께 관리합니다.

## 구현 범위
- `sh_RotationRandomizer` 생성
- `0`, `90`, `180`, `270` 중 하나를 각 조각에 배정
- `sh_PuzzlePieceData` 생성
- 현재 회전값, 정답 슬롯 번호, 이미지 경로 저장

## 예상 결과
- 퍼즐 조각 9개가 각자 회전 상태를 가진 데이터로 정리됩니다.
- 이후 UI 생성 시 회전된 이미지 또는 회전 정보로 사용 가능합니다.

## 선행 준비
- 2차 분할 이미지 9개 생성 완료
- 퍼즐 조각 데이터 저장 방식 결정

## 관련 스크립트
- `ARchive_AI/Assets/Data/Scripts/sh_RotationRandomizer.cs`
- `ARchive_AI/Assets/Data/Scripts/sh_PuzzlePieceData.cs`

## 유니티에서 사용자가 할 일
- 회전 적용 시각 확인용 임시 디버그 UI 또는 로그 준비
- 각 조각 번호와 회전값이 한 번에 확인되도록 Inspector 또는 콘솔 확인

## 완료 기준
- 모든 조각에 허용 각도 중 하나가 적용됩니다.
- 정답 슬롯 번호와 현재 회전값이 데이터로 유지됩니다.
- 같은 조각이 어떤 슬롯에 들어가야 하는지 코드에서 참조 가능합니다.
